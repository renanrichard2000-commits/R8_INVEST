⚙️ Como personalizar este site

🎓 Trocar os cursos de exemplo pelos seus

Abra o arquivo js/courses.js em um editor de texto (Bloco de Notas serve). Lá estão os 2 cursos de exemplo — basta mudar títulos, descrições, módulos e aulas, ou copiar um bloco inteiro para criar um curso novo.

🎬 Colocar os vídeos das aulas

No YouTube/Vimeo, clique em Compartilhar → Incorporar, copie o código e substitua a área .video-screen no HTML. Você também pode hospedar em Hotmart, Kiwify ou outra plataforma e linkar aqui.

💳 Vender de verdade

Este site é a vitrine + área de aulas demonstrativa. Para cobrar alunos e liberar acesso automaticamente, publique os cursos em uma plataforma como Hotmart/Kiwify e use este site como página oficial, ou evolua para um sistema com login e pagamento.

🌐 Publicar na internet

Você pode hospedar este arquivo gratuitamente em serviços como Netlify, Vercel ou GitHub Pages — é só arrastar o arquivo index.html.
